# 01 横磁場イジングモデル（Transverse-Field Ising Model, TFIM）

$$H = -J\sum_i Z_iZ_{i+1} - h\sum_i X_i$$

## どんな模型か

隣り合うスピンを $z$ 方向に揃えようとするイジング相互作用（第1項）と、スピンを $x$ 方向に向けようとする横磁場（第2項）が競合する模型である。2つの項は交換しないため、横磁場は古典的なイジング模型に**量子揺らぎ**を加える役割をする。

- **2つの相と量子相転移**：$h<J$ ではスピンが $z$ 方向に揃った秩序相（強磁性）、$h>J$ では $x$ 方向を向いた無秩序相（常磁性）になる。$h=J$ で、絶対零度でも量子揺らぎによって起こる**量子相転移**がある。
- **厳密に解ける**：1次元では Jordan-Wigner 変換で自由フェルミオンに帰着し、厳密に解ける（P. Pfeuty, Ann. Phys. 57, 79 (1970)）。
- **古典系との対応**：1次元の量子系の基底状態は、2次元の古典イジング模型と対応している（量子-古典対応）。相転移点の臨界指数も2次元古典イジング模型と同じになる。
- **実験との関係**：1次元イジング磁性体 CoNb₂O₆ に横磁場をかける実験や、リュードベリ原子・イオントラップを使った量子シミュレータで実現されている。量子アニーリングも、横磁場を使って最適化問題を解く手法である。

厳密に解けるのに相転移という非自明な物理を含むため、量子多体系の手法を試すための**基準となる模型**として広く使われている。このリポジトリでも、すべての手法の最初の例として使う。

## 手法の比較

| | 厳密対角化 | Jordan-Wigner変換 | 量子回路（Trotter分解・VQE） |
|---|---|---|---|
| 扱う行列・回路 | $2^n\times2^n$ 行列 | $2n\times2n$ 行列 | $n$ 量子ビットの回路 |
| 計算コスト | $O(2^{3n})$ | $O(n^3)$ | ゲート数は時間発展が $O(nr)$、VQE が $O(np)$ |
| 精度 | 厳密 | 厳密 | Trotter誤差・VQEの変分誤差・測定の統計誤差がある |
| 使える範囲 | 一般のハミルトニアン（小さい $n$ のみ） | 2次形式になる模型のみ | 一般のハミルトニアン |

TFIM は Jordan-Wigner 変換で厳密に解ける特別な模型なので、古典計算機でも大きな $n$ まで計算できる。縦磁場を加えるなどして2次形式でなくなると、古典計算機では厳密対角化しか使えなくなる。量子回路による方法は、そのような一般のハミルトニアンにもそのまま使えることが利点である。

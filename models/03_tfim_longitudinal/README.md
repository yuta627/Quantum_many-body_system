# 03 横磁場イジングモデル＋縦磁場（予定）

$$H = -J\sum_i Z_iZ_{i+1} - h\sum_i X_i - g\sum_i Z_i$$

縦磁場 $g$ を加えると2次形式でなくなり、Jordan-Wigner変換が使えなくなる。厳密対角化と量子回路で、可積分系との違い（熱平衡化など）を調べる。

## Jordan-Wigner変換が使えない理由

Jordan-Wigner変換で2次形式になるのは、粒子数の軸にとったPauli演算子の1サイトの項と、それと垂直な軸の最近接の積だけである（[methods/02_jordan_wigner.ipynb](../../methods/02_jordan_wigner.ipynb)の2節の表）。

この模型には、1サイトの項が$X_j$（横磁場）と$Z_j$（縦磁場）の2種類ある。粒子数の軸にとれるのは1つだけなので、どちらを選んでも、もう一方の1サイトの項に長いひもが残る。

- $X$を粒子数の軸にとる場合（横磁場イジングモデルと同じ選び方）：$Z_j = \left(\prod_{k<j}X_k\right)(c_j + c_j^\dagger)$となり、縦磁場の項が非局所的になる。
- $Z$を粒子数の軸にとる場合：今度は横磁場の項$X_j$に長いひもが残り、さらにイジング項$Z_jZ_{j+1} = (1-2n_j)(1-2n_{j+1})$が4次の相互作用になる。

したがって、どの軸を選んでも自由フェルミオンの問題にはならない。縦磁場によって模型は可積分でなくなり、相互作用のある多体問題になる。
